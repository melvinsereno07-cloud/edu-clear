# SEE Organization Management System

A secure, role-based Flask web application for student-government operations with modules for authentication, accounts, financial obligations, attendance, announcements, organization structure, and Excel reports.

## Run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Then open: http://localhost:5000
